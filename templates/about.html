About

A clean ML demo that predicts silver direction using market feeds + trained models.

How it works
  • Fetches market data from yfinance (SI=F and USDINR)
  • Builds features (lags/returns/time)
  • Uses trained ML models to predict UP/DOWN + confidence
  • Estimates price based on State premium and Purity factor
⚠️ This is an educational project, not financial advice.
