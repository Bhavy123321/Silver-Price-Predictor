About Us

Silver Predictor is an educational machine learning project that predicts whether silver price direction may go UP or DOWN for different horizons (Next Hour, Next Day, Next Month). It also estimates prices by purity and common weights (1g, 10g, 100g), with a State/UT premium adjustment.

What this project provides
  • ML-based direction prediction with confidence score.
  • Purity selection: 999 / 925 / 900 / 800.
  • Estimated prices for 1g / 10g / 100g.
  • State/UT premium logic for local variation.
  • Charts for quick visual understanding.
