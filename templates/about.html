About

This project predicts silver direction (UP/DOWN) using ML models and live market reference data.

How it works
  • Fetches market reference: SI=F (silver futures) + USDINR
  • Converts USD/oz → INR/kg
  • Applies state premium + purity factor
  • ML models estimate direction and confidence
⚠️ This is an educational project. Not guaranteed for real trading decisions.
