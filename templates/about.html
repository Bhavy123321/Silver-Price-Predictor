About

This project predicts silver direction using ML models and market reference values.

How it works
  • Uses market reference (silver futures + USD/INR) when available
  • Converts USD/oz → INR/kg and applies State Premium
  • Applies purity factor (999/925/900/800)
  • ML model outputs direction (UP/DOWN) with confidence
⚠ Educational project — not financial advice.
